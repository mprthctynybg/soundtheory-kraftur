## Overview

Soundtheory Kraftur is a professional sample rate converter delivering audiophile-grade conversion quality with minimal distortion and full control over the dithering and filtering process.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtheory Kraftur** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **SRC Quality** | Ultra-high quality conversion kernel with very low aliasing and distortion |
| **Dither Options** | Multiple noise-shaping and dither algorithms for 16/24-bit output |
| **Batch Mode** | Process entire folder of files for offline mastering workflows |
| **Transparency** | Sub-0.1 dB amplitude deviation from original signal post-conversion |
